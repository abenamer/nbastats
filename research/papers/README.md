# Papers

Put the papers the studies cite here, one file per paper, named `<first-author>-<year>-<short-title>.pdf`, for example `oh-2015-graphical-model-basketball-match-simulation.pdf`. The report of each study links to where every paper can be found.

Commit a PDF only when its licence allows redistribution: a Creative Commons licence shown on the arXiv or journal page, a conference that publishes its papers openly, or an author's own site offering the file. arXiv's default licence does not allow third-party redistribution, so check the licence line on the arXiv page. For every other paper keep the link only and the file out of the repository; a paywalled PDF is never committed.

Reading list for the first study, in order of value, with where the text is open:

1. Oh, Keshri, Iyengar 2015, Graphical Model for Basketball Match Simulation. MIT Sloan; the PDF is on the conference site (open).
2. FiveThirtyEight's forecast archive, github.com/fivethirtyeight/checking-our-work-data (data, not a paper; open).
3. Sandholtz, Bornn 2018, Replaying the NBA. MIT Sloan; arXiv 1812.05170 (check the licence) and Annals of Applied Statistics 2020 (paywalled: link only); the authors' site offers a PDF.
4. Sill 2010, Improved NBA Adjusted +/- Using Regularization and Out-of-Sample Testing. MIT Sloan (open on the conference site; the course-site mirror is a copy).
5. Wolfson, Koopmeiners, Who's good this year? arXiv 1501.07179 (check the licence); Journal of Sports Analytics 2018 (paywalled: link only).
6. Aoki, Assunção, Vaz de Melo 2017, Luck is Hard to Beat. arXiv 1706.02447 (check the licence); KDD proceedings (ACM: link only).
7. Lopez, Matthews, Baumer 2018, How often does the best team win? arXiv 1701.05976 (check the licence); Annals of Applied Statistics (link only).
8. Hubáček, Šourek, Železný 2019, Exploiting sports-betting market using machine learning. International Journal of Forecasting (paywalled: link only; the authors' page may offer a preprint); the re-run against Pinnacle odds, arXiv 2107.08827 (check the licence).
9. Misadventures in Monte Carlo, Journal of Sports Analytics, doi 10.3233/JSA-170220 (paywalled: link only; the authors are on the journal page).
10. Štrumbelj, Vračar 2012, Simulating a basketball match with a homogeneous Markov model. International Journal of Forecasting (paywalled: link only).
