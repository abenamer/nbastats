# Papers

This directory holds no papers. The studies cite and link them; the table below lists every paper the studies cite, with a link to where it can be read. A local copy may be dropped here for reading and stays untracked: the folder is ignored (`research/papers/*.pdf` in `.gitignore`). Name local copies `<first-author>-<year>-<short-title>.pdf`, for example `oh-2015-graphical-model-basketball-match-simulation.pdf`.

The page-referenced verdicts from the check of 2026-10-23 are in `../basketball-simulation-accuracy-gap/notes/verification/`.
